# محفظتي — Crypto Portfolio Tracker

محفظة عملات رقمية عربية بسيطة ومجانية.

## المميزات
- إضافة أصول (كمية + سعر شراء)
- أسعار حية من Binance API العامة (بدون مفاتيح)
- حساب القيمة الحالية والربح/الخسارة
- الحفظ محلياً في المتصفح (localStorage)
- واجهة عربية RTL

## التشغيل
افتح `index.html` في المتصفح، أو انشر على Vercel/Netlify.

## ملاحظة
هذه أداة تتبع فقط — ليست نصيحة استثمارية ولا تنفذ صفقات.
